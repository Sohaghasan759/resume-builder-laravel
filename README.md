# Laravel Docker TEX ➜ PDF Converter

`.tex` ফাইল আপলোড করলে Laravel + Docker এর মাধ্যমে `pdflatex` দিয়ে compile হয়ে PDF তৈরি হয় এবং user সরাসরি PDF download করতে পারে।

## Features

- Upload `.tex` file
- Convert TEX to PDF using `pdflatex`
- Laravel Controller based processing
- Dockerized PHP environment
- MySQL support
- Automatic PDF download
- Secure file validation

## Technology Stack

- Laravel 13
- PHP 8.4
- Docker
- MySQL 8.4
- TeX Live / pdflatex
